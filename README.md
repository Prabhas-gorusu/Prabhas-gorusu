This is a personal portfolio website built using **HTML5** and **Tailwind CSS**. It showcases my **education, projects, skills, and contact details** in a clean, responsive design.

## 🚀 Features

* **Responsive Design** – Works across desktop, tablet, and mobile devices.
* **Hero Section** – Highlights career focus and profile image.
* **About Section** – Academic background and location details.
* **Projects Section** – A showcase of selected projects with GitHub link.
* **Skills & Tools** – Technical skills and tools I use.
* **Contact Section** – Easy access to email, phone, and social profiles.

## 🛠️ Tech Stack

* **Frontend:** HTML5, Tailwind CSS
* **Deployment Ready:** Can be hosted on GitHub Pages, Netlify, or Vercel

## 📂 Project Structure

## 📌 Deployment

You can easily deploy this portfolio using **GitHub Pages**:

1. Push the code to your repository
2. Go to **Settings > Pages**
3. Select `main` branch → `/ (root)`
4. Save and get your live portfolio link 🎉
